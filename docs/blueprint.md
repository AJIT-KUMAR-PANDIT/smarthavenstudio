# **App Name**: SmartHaven

## Core Features:

- Secure Authentication: Secure user authentication and session management using Logto for HTTPS-based login, signup, and persistent sessions until sign-out. Integrated biometric authentication adds a layer of personalized access control, replacing traditional PIN entry with fingerprint or facial recognition for enhanced security.
- Centralized Dashboard: Intuitive dashboard offering a high-level overview of the smart home, displaying key metrics such as energy consumption, device status, and active scene.
- Device Control: Real-time monitoring and control of IoT devices via MQTT and HTTPS, enabling users to manage devices across various rooms and locations using Javascript, NoSQL, and RxDB locally.
- AI-Powered Scene Automation: Smart Scene Creation: AI analyzes user habits and device capabilities to suggest optimized and new, creative scene configurations. The system will "tool" and refine scenes over time based on user feedback and environmental data. Additionally, automate actions based on triggers using routes such as sunset/sunrise.
- Customizable Analytics and Logs: Detailed analytics dashboard displaying energy consumption patterns (electricity) and system logs for troubleshooting and optimization, including notifications. These should all be presented within a customizable and themable interface. It will adapt between a dark, light, and system based themes and offer simple editable menu options in the settings.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke a sense of sophistication and intelligence.
- Background color: Very dark gray (#212121) for a sleek and modern look with a focus on content.
- Accent color: Electric blue (#3F51B5) to draw attention to key interactive elements.
- Clean and modern sans-serif fonts.
- Animated, minimalist icons that provide clear visual cues and enhance user interaction.
- A dynamic and responsive grid layout that adapts seamlessly to both web and mobile platforms, providing an optimal viewing experience across devices. The menu and dashboards adapt between mobile and web views.
- Subtle transitions and animations to create a fluid and engaging user experience.
